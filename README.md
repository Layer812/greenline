# 緑の稜線を越えて

緑の丘を越えて接近する暴走ロボットを、4種類の武器で迎撃するブラウザゲームです。迷彩ヘルメットの防衛隊員越しに照準を合わせ、防衛線を守ります。

**完成版 v1.1.0**

## プレイ

**[ブラウザで遊ぶ](https://layer812.github.io/greenline/)**

PCのマウス・キーボードとスマートフォンのタッチ操作に対応しています。インストール不要です。音は初期状態でOFFです。

## 操作

| 操作 | 動作 |
| --- | --- |
| マウス移動 | 照準 |
| 左クリック長押し | ショットガン・機関銃・擲弾砲の射撃 |
| 1 / 2 / 3 / 4 | ショットガン / 機関銃 / 擲弾砲 / 二丁拳銃 |
| 左・右クリック交互 | 二丁拳銃。左手・右手の銃を交互に発射 |
| 右クリック5回 | ショットガン・機関銃の補給開始 |
| R | 擲弾砲・二丁拳銃のリロード |
| P | 一時停止・再開 |
| 全画面 | ゲーム画面を全画面表示 |
| 状況を報告 | 戦果とプレイ用リンクを入力したXの投稿画面を開く |

武器は選択パネルからも切り替えられます。補給中に別の武器へ持ち替えても、補給は継続します。

## ルール

- ライフは10。敵の接触、または手前での擲弾爆発で1減ります。
- ライフ0で「あなたは防衛線を守れませんでした」と表示され、ゲーム画面が赤く染まります。
- 30秒ごとにWAVEが上がり、敵の接近速度・出現密度・装甲が強化されます。
- WAVE 3以降、ときどき鉄灰色の重装甲機が出現します。同時に出現する重装甲機は1体までです。
- ハイスコアは利用中のブラウザに保存します。オンラインランキングはありません。

## 武器

| 武器 | 弾数 | 特徴 | 補給 |
| --- | ---: | --- | --- |
| ショットガン | 8 | 9発の散弾。近距離向き | 右クリック5回 → 1.6秒 |
| 機関銃 | 96 | 約8秒の連続射撃 | 右クリック5回 → 4秒 |
| 擲弾砲 | 3 | 遠くほど広く強い範囲攻撃。手前では自傷に注意 | 弾切れ時自動、またはR → 5秒 |
| 二丁拳銃 | 左12・右12 | 左右交互の単発射撃。通常機は3発で撃破 | 弾切れ時自動、またはR → 1.2秒 |

## 戦果報告

右上の「状況を報告」で、点数・WAVE・残りライフ・撃破数・状況・装備・プレイ用リンクをXの投稿画面に渡します。内容を確認・編集し、自分で投稿できます。プレイ中は一時停止します。

## ソースと仕様

- [詳細仕様](SPEC.md)
- [変更履歴](CHANGELOG.md)
- `index.html`：画面・操作説明・スタイル
- `game.js`：ゲームロジック・Canvas描画・効果音・戦果報告
- `.nojekyll`：GitHub Pagesで静的ファイルとして配信する設定

外部ライブラリ・画像素材・音声ファイルは不要です。人物、ロボット、地形、着弾効果はCanvasで描画し、効果音はWeb Audioで生成します。参考画像そのものは配布物に含めていません。

## ローカル実行

`index.html`をブラウザで開くか、このディレクトリで次を実行します。

```sh
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** を選択して保存します。公開先は `https://layer812.github.io/greenline/` です。

## 保存・通信

プレイ中の記録はサーバーへ送信しません。ハイスコアだけをブラウザのlocalStorageに保存します。「状況を報告」を押すと、戦果を含むXの投稿画面へ移動します。

## 対応範囲

スマホは横向き推奨です。タッチ操作の判定は自動テストで検証していますが、実機での操作感は未検証です。全画面表示と音声の可否はブラウザの機能・設定に依存します。

## スマホの操作（v1.1.0）

- 射撃：狙う場所をタップ。機関銃・散弾・擲弾は長押しで連射、ドラッグで照準移動。
- 二丁拳銃：ゲーム画面の左半分で左銃、右半分で右銃。必ず左右交互、タップ位置を狙います。
- 機関銃・散弾の補給：同じ場所を素早く2回タップ。1回目は通常射撃、2回目で補給開始（空弾倉でも可能）。補給時間・ゲージはPCと共通です。
- ダブルタップ判定：1回目は200ms以内・移動20 CSS px以内、指を離してから300ms以内・32 CSS px以内に2回目。長押し・ドラッグ・武器切替後は対象外。
- 擲弾・拳銃：弾切れで自動補給、または画面下のリロードボタン。武器選択・一時停止も画面のボタンで操作します。
- PCでは従来どおり、二丁拳銃は左右クリック、機関銃・散弾の補給は右クリック5回です。
